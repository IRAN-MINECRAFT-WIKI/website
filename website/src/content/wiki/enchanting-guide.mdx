جادوها (Enchantments) به ابزارها، سلاح‌ها و زره‌ها قابلیت‌های ویژه می‌دن. در این راهنما، همه‌ی روش‌های enchanting، بهترین جادوها برای هر آیتم و استراتژی‌ها رو معرفی می‌کنیم.

## روش‌های Enchanting

### ۱) Enchanting Table
- **ساختار:** ۴ Obsidian + ۲ Diamond + ۱ Book
- **نیاز:** XP + Lapis Lazuli
- **حداکثر:** Level ۳۰ (با ۱۵ Bookshelf دورش)

#### نکات Enchanting Table
- با ۱۵ Bookshelf در فاصله‌ی ۲ بلاک، Level ۳۰ فعال می‌شه
- Bookshelf‌ها باید با یه بلاک فاصله باشن (با Air بینشون)
- با placement درست، ۳ گزینه‌ی Level 1, 10, 30 نشون داده می‌شه

### ۲) Anvil + Enchanted Book
- **ساختار:** ۳۱ Iron Ingot (۴ Iron Ingot + ۳ Iron Block)
- **نیاز:** Enchanted Book + XP
- **مزیت:** می‌تونی جادوهای خاص رو انتخاب کنی

### ۳) Villager Trading
- **Librarian** با Lectern می‌تونه Enchanted Book بده
- با Curing Zombie Villager، قیمت‌ها ۳۰-۷۰٪ کم می‌شن
- **Mending Book** رو می‌تونی از Librarian بگیری

## استراتژی‌ها

### Best Sword (ندرایت)
```
Sharpness V + Fire Aspect II + Looting III + Unbreaking III + Mending
```
- با Mending، عملاً ابدی
- با Fire Aspect + Looting، دراپ بیشتر و آسیب آتشی

### Best Pickaxe (ندرایت)
```
Efficiency V + Fortune III + Unbreaking III + Mending
```
- با Fortune III، Diamond ۴ برابر دراپ
- با Mending، عملاً ابدی

### Best Bow
```
Power V + Flame + Infinity + Unbreaking III
```
- با Infinity، فقط ۱ تیر لازم
- نکته: در Java، Infinity + Mending با هم کار نمی‌کنن

## نکات مهم

### مدیریت XP
- با **Enderman Farm** یا **Mob Farm**، XP نامحدود
- با **Mending** روی همه‌ی ابزارها، XP رو به دوام تبدیل کن
- با **Fishing**، می‌تونی Enchanted Book (با Mending) بگیری

### تناقضات (Incompatibilities)
- **Sharpness + Smite + Bane of Arthropods:** فقط یکی
- **Protection + Fire Protection + Blast Protection + Projectile Protection:** فقط یکی
- **Infinity + Mending:** در Java با هم کار نمی‌کنن
- **Silk Touch + Fortune:** فقط یکی
- **Channeling + Riptide:** فقط یکی
- **Frost Walker + Depth Strider:** فقط یکی

### Combining Enchantments
- با **Anvil + Enchanted Book**، می‌تونی جادوها رو ترکیب کنی
- هر ترکیب، هزینه‌ی XP بیشتر داره
- با **Grindstone**، می‌تونی جادوها رو پاک کنی (XP برمی‌گرده)

## نتیجه
جادوها یکی از قدرتمندترین مکانیک‌های ماینکرفت هستن. با انتخاب درست جادوها برای هر آیتم، می‌تونی سلاح‌های ابدی و زره‌های ضدِ همه‌چیز داشته باشی. برای مطالعه‌ی بیشتر، صفحه‌ی **enchantments** و **villager-trading** رو ببین.
