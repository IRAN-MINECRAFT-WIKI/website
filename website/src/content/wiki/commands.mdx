فرمان‌ها (Commands) در ماینکرفت بدراک به شما اجازه می‌دهند کارهای پیشرفته‌ای انجام دهید — از teleport و تغییر حالت بازی تا ساخت ساختارها و کنترل mobها. در این راهنما، مهم‌ترین فرمان‌ها را معرفی می‌کنیم.

## فعال‌سازی Cheats

برای استفاده از فرمان‌ها در survival، باید هنگام ساخت دنیا **"Activate Cheats"** را فعال کنید. در غیر این صورت، فرمان‌ها فقط در creative mode کار می‌کنند.

## فرمان‌های پایه

### `/give`
**توضیح:** آیتم به بازیکن می‌دهد.

**ساختار:**
```
/give <player> <item> [count] [data] [components...]
```

**مثال:** گرفتن ۶۴ الماس
```
/give @s minecraft:diamond 64
```

### `/teleport` (یا `/tp`)
**توضیح:** بازیکن یا entity را به مکان دیگری منتقل می‌کند.

**مثال:** انتقال خودتان به مختصات
```
/tp @s 100 70 200
```

**مثال:** انتقال بازیکن دیگر به خودتان
```
/tp Steve ~ ~ ~
```

### `/gamemode`
**توضیح:** حالت بازی را تغییر می‌دهد.

**مقادیر:**
- `survival` (یا `s`) — بقای
- `creative` (یا `c`) — خلاقانه
- `adventure` (یا `a`) — ماجراجویی
- `spectator` (یا `sp`) — تماشاگر

**مثال:**
```
/gamemode creative
```

### `/time set`
**توضیح:** زمان روز را تنظیم می‌کند.

**مثال:** روز کامل
```
/time set day
```

**مثال:** شب کامل
```
/time set night
```

**مثال:** زمان خاص
```
/time set 6000
```

### `/weather`
**توضیح:** آب و هوا را تغییر می‌دهد.

**مثال:**
```
/weather clear
/weather rain
/weather thunder
```

## فرمان‌های Entity

### `/summon`
**توضیح:** یک entity (mob، item، و غیره) را احضار می‌کند.

**مثال:** احضار زامبی
```
/summon zombie ~ ~ ~
```

**مثال:** احضار اژدها
```
/summon ender_dragon
```

### `/kill`
**توضیح:** entity یا بازیکن را می‌کشد.

**مثال:** کشتن همه‌ی mobهای اطراف
```
/kill @e[type=zombie,r=50]
```

## فرمان‌های جلوه (Effect Commands)

### `/effect`
**توضیح:** اثر وضعیت (status effect) به entity می‌دهد.

**ساختار:**
```
/effect <player> <effect> [seconds] [amplifier] [hideParticles]
```

**مثال:** سرعت ۳ (۶۰ ثانیه)
```
/effect @s speed 60 3
```

**مثال:** جاودانگی موقت (۶۰ ثانیه)
```
/effect @s regeneration 60 5
```

## فرمان‌های ساختار

### `/fill`
**توضیح:** یک محدوده را با بلوک پر می‌کند.

**ساختار:**
```
/fill <from> <to> <block> [mode]
```

**مثال:** پر کردن یک ۱۰x۱۰ با سنگ
```
/fill ~ ~ ~ ~10 ~10 ~10 stone
```

### `/setblock`
**توضیح:** یک بلوک در مختصات قرار می‌دهد.

**مثال:**
```
/setblock ~ ~ ~ diamond_block
```

### `/clone`
**توضیح:** یک ساختار را از یک جا به جای دیگر کپی می‌کند.

**مثال:**
```
/clone <from-x> <from-y> <from-z> <to-x> <to-y> <to-z> <dest-x> <dest-y> <dest-z>
```

## فرمان‌های مفید دیگر

### `/locate`
**توضیح:** مختصات نزدیک‌ترین ساختار (Village، Stronghold، و غیره) را نشان می‌دهد.

**مثال:**
```
/locate village
/locate stronghold
/locate temple
```

### `/seed`
**توضیح:** seed دنیا را نشان می‌دهد.

### `/list`
**توضیح:** لیست بازیکنان آنلاین سرور را نشان می‌دهد.

### `/spawnpoint`
**توضیح:** نقطه‌ی تولد بازیکن را تنظیم می‌کند.

**مثال:**
```
/spawnpoint @s ~ ~ ~
```

## Selector Targets

`@` برای انتخاب بازیکنان/entityها استفاده می‌شود:

| Selector | معنی |
|----------|------|
| `@s` | خودتان |
| `@p` | نزدیک‌ترین بازیکن |
| `@a` | همه‌ی بازیکنان |
| `@e` | همه‌ی entityها |
| `@r` | بازیکن تصادفی |

**فیلترها:**
- `[type=zombie]` — فقط زامبی‌ها
- `[r=10]` — شعاع ۱۰ بلوک
- `[distance=..10]` — تا ۱۰ بلوک دور
- `[name=Steve]` — با نام خاص

## نکات پایانی

- فرمان‌ها با `T` یا `/` باز می‌شوند.
- `Tab` برای autocomplete استفاده کنید.
- `F3` مختصات خودتان را نشان می‌دهد (برای `tp` و `fill`).
- در **Bedrock Edition**، برخی فرمان‌ها متفاوت از Java هستند.
